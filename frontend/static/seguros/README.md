# Logos de aseguradoras

Si pones aquí el logo oficial de una aseguradora con el nombre `<id>.svg` (o `.png`), la página pública lo muestra.
Sin archivo se usa un distintivo con el nombre, así que nada se rompe.

Los ids están en `src/lib/specialty/insurers.ts` (por ejemplo `gnp.svg`, `axa.svg`, `metlife.svg`).
Usa solo logos que tengas derecho a mostrar: son marcas registradas de cada aseguradora.
